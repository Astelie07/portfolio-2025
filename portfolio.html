Altea Hackathon Project

  • Date: December 2023
  • Other team members: Esther Amegnisse, Nabil Boukhorissa, Tom Bihoreau, Hugo Delacour

Altea was created during a hackathon in December 2023, where we imagined a website similar to LinkedIn to solve an issue faced by many students: the lack of responses from recruiters. The goal of the platform is to create a sense of urgency, encouraging companies to respond faster through a reputation and rating system.

We had to complete this project in 24 hours and present it to the rest of our class. This project allowed us to work on UX/UI design while integrating specific needs for both students and recruiters, with a different interface for each type of user.

Figma Dashboard

  • Date: November 2023
  • Client: Bear Studio

As part of our course, we had the opportunity to work with Ivan Dalmet from Bear Studio to learn Figma best practices. The goal was to design a dashboard for developers, allowing them to deploy websites from a GitHub repository.

Here were the specific instructions we were given:

  • Create a dashboard in Figma.
  • Target: 1440x900px laptop screen.
  • Use color styles and components.
  • Apply auto-layout for a responsive layout.

Blender Modeling

  • Date: September - October 2023
  • Software used: Blender

The goal of this project was to create a scene inspired by the video game "Sea of Thieves" using Blender. This project allowed me to apply various 3D modeling techniques to create an immersive and realistic environment.

The modeled elements include a table, a treasure map, and paper scrolls. These objects were integrated into a scene representing a typical pirate workspace.

The last image shows the texture applied to the treasure map to give it a realistic and aged appearance.

Dashboard

The goal of this project was to create a dashboard showing the pandemic situation in the Drôme department. Users can view different statistics through interactive graphs created from dynamic data.

The website was designed to learn how to interact with a database, integrating interactive graphs and regularly updated data. It is only accessible to IUT members for educational purposes.

Among the included graphs, we followed the requirement of presenting at least 4 different types, including one graph that had not been covered in class, in order to add an innovative touch to the project.
